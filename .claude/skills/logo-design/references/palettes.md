# Palettes

Start from the project's existing tokens if there are any; these are for
new brands or for contrast in exploration. Each: background, foreground,
accent. Check the accent against the background for ≥ 3:1 contrast (non-text
graphics, WCAG 1.4.11).

## Tech / developer
- **Terminal violet** — `#171717` / `#f5f5f5` / `#a78bfa`
- **Deep navy** — `#0b1220` / `#e6edf7` / `#38bdf8`
- **Ink teal** — `#0f1715` / `#eef5f3` / `#2dd4bf`
- **Graphite amber** — `#1a1a1a` / `#fafafa` / `#f59e0b`
- **Paper blue** (light) — `#ffffff` / `#111827` / `#2563eb`

- **Clay** — `#faf6f1` / `#3a2e28` / `#c9785b`

## Rules
- One accent. A second accent must earn its place.
- The mark must survive with the accent removed (monochrome test).
- Avoid pure `#000`/`#fff` tiles next to UI that uses near-black/near-white.
