**rconsole 4.4.5** fixes the world size, for real this time.

## Fixed

- **World size still showed a few MB** after 4.4.3. Folders that rconsole could list but not enter (read without search permission) made every file size fail quietly as 0, and nothing was flagged, so the permission repair from 4.4.3 never ran. Those failures now count as unreadable: rconsole repairs the folders (group read and search, nothing writable) and measures again.
