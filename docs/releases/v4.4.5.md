**rconsole 4.4.5** shows the real size of a world.

## Fixed

- **World size showed a few MB instead of the real size** (4.6 MB for a 1.2 GB world). The size code statted the files of a folder in parallel and added them with `total += await …`, which reads the running total before waiting; the parallel additions overwrote each other, so a folder of 142 region files counted as one file. This has been wrong since rconsole first showed world sizes.
- Files whose size can't be read now count as unreadable, so the folder repair from 4.4.3 runs when it is needed.
