**rconsole 4.1.1** makes rconsole lighter and steadier.

## Better

- **No pile-up when the server hangs:** while RCON is unreachable, commands fail at once for a few seconds instead of each waiting 5 seconds, and at most 50 can queue.
- **Faster long replies:** a reply of exactly 4096 bytes (inventories, long lists) no longer waits a fixed 150 ms; rconsole asks the server when it is done.
- **Fewer processes:** open tabs that ask for the server state at the same moment share one `systemctl` call, and the server software is detected at most every few seconds during startup instead of on every refresh.
- **Downloads:** a backup that can't be read ends the download with an error instead of leaving it hanging.
- **Tidy:** helper job results older than 30 days are removed, and each session can open at most 8 log views.
