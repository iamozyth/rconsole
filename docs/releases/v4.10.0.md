**rconsole 4.10.0** turns Server → Files into a file manager for the whole server folder.

## New

- **Browse** the server folder: folders first, sizes, last change, a filter, breadcrumbs. Files open on the right: text files up to 1 MB in the editor, anything else with its size and a download.
- **Edit any text file** (not only plugin configs), with the syntax check, the diff before saving and Revert as before. A save only goes through over the version you opened, so a plugin writing the same file meanwhile isn't silently overwritten.
- **Upload** files into the open folder, or drop them on the list. Uploads are resumable. An archive can be unpacked into a new folder, with the same checks as world imports.
- **Download** files, and folders as `.tar.gz`.
- **New file, new folder, rename or move.**
- **Delete** archives the file or folder into `deleted-files/` in the backup folder first.

## Safety

- Links are shown but never followed. `instance.json` and rconsole's own `.rconsole*` folders can't be changed, and the active world can't be moved or deleted here (World does that).
- Saving `server.properties` keeps rconsole's RCON settings, so an edit can't lock rconsole out.
- Every change runs in the helper as the Minecraft user, which checks each path again. Files is for admins of the shown server.
