**rconsole 4.1** hardens sign-in and updates.

## New

- **Stay signed in across restarts.** Switching servers, updating rconsole or a crash no longer sign everyone out. Only a hash of each session token is stored.
- **Recovery codes for 2FA.** `node cli.js user totp <name>` now prints ten one-time codes. On the sign-in page, **Use a recovery code** lets you in when the phone is gone.
- **Mandatory 2FA.** `REQUIRE_2FA=admin` (or `all`) in `/etc/rconsole.env` makes 2FA a requirement for local accounts of that role.
- **Signed updates only.** With `SELF_UPDATE_SIGNERS`, rconsole updates itself only to release tags you signed with your SSH key, so a stolen GitHub account can't push code to your server. See "Signed updates only" in the README.

## Better

- **HSTS** is sent when your reverse proxy serves rconsole over HTTPS.
- Map links of ended sessions are cleaned up regularly.
- Tests run on Node.js 18, 20, 22 and 24.
