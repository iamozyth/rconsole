**rconsole 4.20.0** tries an update on a copy of the server before players get it.

## New

- **Try an update first** (Server → Updates, admins): for servers rconsole installed, a copy of the server starts with the current version and then with the update, next to the running server, without players and cut off from the internet.
- The result says whether the update comes up, how long it takes, which plugins no longer start, and the warnings and errors only the update logs, with their stack traces; a start that fails shows its last log lines and the crash report.
- **Try first** next to every newer build and version; builds tried before say how they did.

## Install

- New unit `rconsole-try@.service` (the copy may reach this machine only) and a polkit rule for it. The installer and the self-update put both in place; manual installs copy `rconsole-try@.service` to `/etc/systemd/system/` and `50-rconsole.rules` to `/etc/polkit-1/rules.d/` again.
