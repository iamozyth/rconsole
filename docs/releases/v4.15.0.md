**rconsole 4.15.0** gives rconsole's own updates a home in Settings and cleans up Server → Updates.

## New

- **Settings → Updates** is where rconsole updates itself: the installed version, commit and Node.js, its state, and one button (**Update to 4.15.0**, or **Install Node.js 24** when that is what's missing). Below it: what the update brings, the steps while it runs, the result afterwards, the automatic check switch and where updates come from (repository, branch, signed releases only or not).
- **Changelog rows** show the release as a tag and the change's title without the repeated version, with when it landed; rows with a description open in place. **On GitHub** opens the full comparison.
- **Check now** next to the version asks GitHub right away.

## Changed

- **Server → Updates** is about the Minecraft server only: its software and its plugins or mods, one row each with at most one action (**Update to #209**, **Review**). The **Options** button is gone; the install options are always shown below as two settings rows (back up first, warn players) with **Roll back** in their header. The newest build's Update is no longer repeated in the builds table; older builds have **Install**.
- When rconsole has an update, Server → Updates shows one line pointing to Settings → Updates instead of a second Update button.
- The sidebar notice, the dot (now on Settings and its Updates tab), the version under your name, the dashboard's Updates tile, notifications and Problems' Node.js hint all lead to Settings → Updates.
- Settings → System no longer has the rconsole panel (it is part of Settings → Updates), and its "Backups and updates" panel is "Backups". The check switch said "every day"; rconsole checks every 6 hours.
- The search palette has **Check for server updates** and **Update rconsole**.
