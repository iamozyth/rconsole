**rconsole 4.7.0** adds automation tasks and requires Node.js 24 or newer.

## Node.js requirement

Node.js 18 and 20 are out of upstream support, and Debian's own packages (18 on Debian 12, 20 on Debian 13) no longer qualify. rconsole now gets Node.js 24 LTS from [NodeSource](https://github.com/nodesource/distributions) when the system's is older.

### Upgrading

Click **Update** as usual. The update to 4.7.0 still runs with the previous version's updater, which doesn't install Node.js, so rconsole 4.7.0 first starts on the Node.js you have and says so: Problems shows "Node.js v20… is too old" and **Server → Updates** shows **Needs Node.js 24** next to rconsole, with an **Update** button. Click it once more: the updater adds NodeSource's repository, installs Node.js 24 and restarts rconsole. Minecraft keeps running.

Without the button: `sudo systemctl start rconsole-selfupdate.service`. If NODE_BIN in `/etc/rconsole.env` points to a node you installed yourself (not `/usr/bin/node`), rconsole leaves it alone and asks you to update it there.

## Automation

Scheduled tasks now support chained steps, cron schedules, event triggers, and per-server ownership.

- **Chained steps**: a task runs up to ten steps in order: tell players, run a command, wait, back up the world, restart or stop with a countdown, start the server, and "only go on if nobody is online". For example: warn, wait four minutes, back up, restart.
- **Cron schedules** next to daily and weekday times, with the next three runs shown while you type.
- **Event triggers**: the server started, it crashed (stopped without rconsole stopping it), nobody online for a while, or the log shows a line. Each event task has a cooldown so it can't loop.
- **Per server**: every task belongs to a server. Tasks for a server rconsole installed run through its console and unit while another server is shown (restart, stop, start, warnings, commands); backups and player-based steps need the shown server.
- **Ready-made tasks** in the form: nightly restart, backup then restart, restart when empty, start again after a crash, backup every two hours.
- Tasks can be edited, and the list shows which step a running task is on.

## Other changes

- **Node.js 24 or newer** (`engines.node`). Tests run on 24 and 26; 18, 20 and 22 are no longer tested.
- **Installer**: installs Node.js 24 from NodeSource (key in `/etc/apt/keyrings/nodesource.asc`, pinned above the distribution's `nodejs`) unless Node.js 24 or newer is already installed. Other distributions: install Node.js 24 yourself first.
- **Self-update** installs the Node.js a new version needs before restarting, also when there are no new commits. If that fails, it stays on the old version and says why. The updater may now take up to 15 minutes (apt).
- Tasks saved before 4.7 become daily tasks with one step, for the server shown at the update. Before, tasks ran on whichever server rconsole showed, so switching servers moved every task to the new one.
- Tasks are now saved in `automation.json`. The old `tasks.json` stays untouched, so going back to an older version (or an automatic rollback after a failed update) keeps working with the tasks you had before 4.7.
