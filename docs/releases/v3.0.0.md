The first public release of **rconsole**: a self-hosted web console for your Minecraft server.

![rconsole console](https://raw.githubusercontent.com/iamozyth/rconsole/v3.0.0/docs/screenshots/console.webp)

## Install

On a Debian or Ubuntu host where your Minecraft server runs as a systemd service:

```sh
curl -fsSL https://raw.githubusercontent.com/iamozyth/rconsole/main/install.sh | sudo bash
```

The installer finds your server, turns on RCON, sets up users, permissions, backups, systemd units and polkit, and creates your first account. It is safe to run again and has `--dry-run` and `--uninstall`.

## What's in it

- **Console**: live log with filters, command prompt with autocomplete (commands, players, game rules, plugin commands) and a command palette (Ctrl/⌘ K).
- **Server control**: start, stop, restart with in-game countdowns; maintenance mode.
- **Players**: whitelist, operators, bans; player history from your logs; detection of internet scanners with ban and firewall suggestions.
- **Worlds and backups**: switch, create and delete worlds; per-world backups with retention, download and restore; scheduled restarts, backups and commands.
- **Updates**: one check for rconsole, the server software and plugins. Paper/Folia updates warn players, disconnect everyone, back up the world while nobody plays, swap the verified jar and start again, with rollback.
- **Plugins and mods** from Modrinth: identify, update, install, enable, disable, roll back.
- **Settings**: `server.properties` as a typed form with a review step.
- **Insights**: TPS, players, CPU and memory charts; log search across rotated logs; audit trail.
- **Integrations**: ntfy push notifications with one-tap actions and quiet hours, squaremap/BlueMap inside rconsole, Prometheus `/metrics`.
- **Works with** Paper, Purpur, Folia, Spigot, Bukkit, Fabric, Quilt, Forge, NeoForge and vanilla.
- **Security**: scrypt passwords, optional TOTP 2FA, brute-force lockout, strict CSP, sandboxed systemd service, privileged work only through validated helper jobs; self-update with automatic rollback.
