**rconsole 4.10.1** opens files in Server → Files that only the server itself can read.

## Fixed

- **"EACCES: permission denied" when opening some plugin configs.** Some plugins save their files readable only by the server's user (0600), for example VoxyServerSide's `vss-server-config.yaml`. rconsole runs as its own user and can read the server folder only through the server's group, so opening such a file failed. rconsole now has the helper read it as the server's user. The same goes for folders a plugin keeps to itself. Saving already went through the helper and keeps the file's permissions as they are. Downloading such a file still isn't possible and now says so plainly.
- **"null" under the hint in Server → Files** in folders without common config files.
