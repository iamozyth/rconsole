**rconsole 4.4** reorganises the console around a dashboard, one player list and a place per job, in the style of UniFi's consoles, and fixes what a live test of 4.3 found.

## New layout

- **Dashboard** is the new home: server state, TPS, players, memory, last backup, problems, updates and disk as tiles, the last six hours as charts, who's online, daily activity and recent changes.
- **Server switcher** at the top of the sidebar: every server rconsole runs, with its state, *Manage servers* and *New server*. It replaces Server → Servers.
- **Players** is one table of everyone the server knows, with whitelist, operator and ban status, counts per filter and a search. A row opens the player's profile as a side panel, which now has whitelist, operator, ban and log search for offline players too, and their history (first and last visit, sessions, playtime, last address).
- **Problems moved to a bell** in the top bar with a count. Each kind can be **muted** when it's known and harmless; it then leaves the list, the bell and notifications. Generic errors are titled by their message instead of "Error".
- **Backups** has its own place: backups on this machine, offsite copies and their settings.
- **World** holds the worlds and the **Map**.
- **Chat** is part of the Console (All output / Chat), with the message box under it.
- **Automation** is the new name of Schedule; Server → Configs is now **Files**; Insights → Audit is now **Activity**.
- **Settings**: Account, Users & sign-in (single sign-on and accounts), Notifications (split into where alerts go and what to send) and System (version, self-update, the server's configuration and the rconsole URL, now set in one place).
- **Drawers**: New server, New world, New task and the offsite settings open from the right over the list instead of pushing it away.
- Old links and bookmarks (and links in notifications sent before) still work.

## Also new

- **Change your own password** under Settings → Account. You stay signed in; other devices are signed out.
- **Map**: rconsole finds BlueMap, squaremap or Dynmap and their port and offers to show it, with a warning when the map listens on every address. `MAP_URL` still works and wins.
- **Quick actions**: pin your own commands next to Save world, Clear weather, Day and Night.
- The console dims times and sources, colours levels and tags plugin names, so the message stands out.
- Logs opens with the latest warnings and errors; Files offers each plugin's main config and folds per-player folders like `userdata/`.
- On tablets the sidebar becomes an icon rail; on phones the status strip is one row and sub-tabs scroll.

## Fixed

- **A reverse proxy that isn't in `TRUST_PROXY`** is now reported under Problems and System. Until it is set, rconsole sees every visitor as the proxy: five wrong passwords from anyone lock out all password sign-ins, and HSTS and secure cookies stay off.
- **Worlds on Minecraft 26.x** show their nether and end (kept under `dimensions/`), and folders rconsole can't read are logged instead of silently counting as 0 bytes.
- **Memory limits** are capped at the machine's RAM; a limit above it never applied.
- The **About** page showed "Not set" for the rconsole URL saved under Notifications.
- **New server** starts with the most memory that still fits next to the other servers and flags a choice that doesn't.
- rconsole's own status check racing a shutdown no longer shows up as an error after every restart. "Without Vault" warnings now suggest VaultUnlocked, which is on Modrinth.
- Audit entries name the installed plugin instead of its Modrinth ID, and self-updates show old → new.
- Plugins counts jars that wait for a restart separately; "1 change waits", not "wait"; no stray "·" under Power.

## Faster

- Pages and scripts are sent compressed and kept by the browser between visits (revalidated by ETag). API answers over 1 KB are compressed.

## Updating

Self-update from Settings → System. Nothing to migrate. The capped memory limit applies from each server's next restart.
