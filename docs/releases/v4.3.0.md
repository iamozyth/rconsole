**rconsole 4.3** hardens the Minecraft servers rconsole runs and makes them faster out of the box.

## Security

- **RCON is closed to other machines.** RCON sends its password in plain text and only rconsole on the same machine needs it. The new `rconsole-limits.service` drops RCON connections from outside with an nftables rule (`RCON_FIREWALL=off` turns it off). Problems warns when an RCON port is reachable anyway.
- **Servers can't see each other.** Each `rconsole-mc@` server sees only its own folder: not the other servers, the attached server or the backups. Its `instance.json` is read-only to it, so a plugin can't raise its own memory or change its command line. No capabilities, its own IPC namespace, other processes hidden.
- **Velocity with modern forwarding.** A server created behind a Velocity proxy gets the proxy's forwarding secret and listens on 127.0.0.1 only, so nobody can join it directly with any name.
- **Helper jobs no longer carry rconsole's secrets** (RCON and web passwords, SSO and offsite keys), so a plugin can't read them from a running backup.
- **Secure defaults for new servers**: whitelist with your Minecraft name, `enforce-secure-profile`, no player IPs in the log.
- **Port lock** (optional per server): the server may only listen on its own ports.
- **Plugins** installed by hand or changed since rconsole installed them are marked.
- Mod-loader updates run in a clean folder, so a planted link can't redirect them into another server.
- The installer offers `kernel.yama.ptrace_scope=1` and an opt-in sandbox for the attached Minecraft service.

## Performance and stability

- **Memory limits.** Each server gets a limit of its heap plus room for Java, and the kernel stops a Minecraft server before rconsole or sshd when memory runs out. Creating a server whose memory doesn't fit the machine asks first.
- **Faster backups**: zstd when installed, so autosave is off for far less time. Autosave is now turned back on even if the server didn't answer `save-off`.
- **Recommended settings** for new servers: `simulation-distance=6`, asynchronous chunk writes, and anti-xray and faster explosions on Paper.
- **Generational ZGC** as a Java tuning profile for big heaps on Java 21+; Java's defaults now always use G1.
- **Pre-generate** a world with Chunky from Worlds.
- Problems warns when the machine swaps or is almost out of memory.

## Fixed

- A crash-looping server can be stopped, and five crashes in ten minutes stop it (*Crashed repeatedly*).
- A new server's game port can no longer collide with another server's RCON port.

## Updating

Self-update installs and starts `rconsole-limits.service`. For the firewall and zstd backups run `apt install nftables zstd`, or run the installer again, which also offers the ptrace setting. Restart each server once so it gets the new sandbox and memory limit.
