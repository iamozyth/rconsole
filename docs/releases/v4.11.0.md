**rconsole 4.11.0** shows what an rconsole update brings and how it is going, on Server → Updates.

## New

- **What's new** is back on Server → Updates (since 4.4.0 it sat hidden in Settings → System): every pending commit with its description (click to expand), the release it ships as a tag that opens its notes, and the version it updates to ("rconsole 4.11.0 is available").
- **Update progress in place**: Download, Install Node.js (when the new version needs a newer one), Check the new version, Update system files, Restart rconsole and Back online, each with its status and how long it took. While rconsole restarts the page waits and says so, then reloads on the new version by itself.
- **The result stays**: after the reload the card shows the finished steps, what changed and anything installed along the way for an hour (or until you dismiss it), instead of a badge that quietly resets.
- **Node.js in two steps**: when the update ran with an updater too old to install Node.js (updates from before 4.7), the card shows "Install Node.js 24" as the next step and starts it on its own if you started the update in this browser.

## Changed

- The confirm dialog no longer says everyone is signed out; sessions survive restarts since 4.1.
- `bin/self-update.sh` reports the step it is on, when each step started and the steps still to come in its status file. Older status files (no steps) are still shown, read from their messages.
- Settings → System links to Server → Updates instead of showing a hidden copy of the changelog.
