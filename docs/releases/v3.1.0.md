**rconsole 3.1** is about keeping your server safe: it now notices when something goes wrong, keeps copies of your worlds off the machine, and helps you find the cause of lag.

## New

- **Problems** (Insights → Problems):
  - **What it finds:**
    - crashes and crash reports
    - out-of-memory
    - the watchdog's "server has stopped responding"
    - plugins or mods that fail to load
    - exceptions in plugins
    - other errors and "Can't keep up" warnings
  - **How it shows them:** read from your logs and grouped, with the plugin, the exception line, counts and a jump into log search.
  - **systemd failures** count as crashes even when the log shows nothing, for example when the kernel's OOM killer stops the server.
  - **Alerts:** a red dot marks new problems. With ntfy, crashes and plugin failures alert you right away; other errors arrive as a daily digest.
- **Offsite backups** (Worlds → Offsite copies):
  - **Where to:** upload backups to any S3-compatible bucket: Backblaze B2, Cloudflare R2, AWS S3, Wasabi, MinIO.
  - **Encryption (optional):** backups are encrypted on your machine before upload (AES-256-GCM, passphrase-derived key).
  - **Automatic uploads** after every backup, with retries and per-world retention.
  - **Bring back:** downloads a copy into the backup folder for the usual restore.
- **spark profiler** (Insights → Metrics):
  - **Profile 30 s** and **Health report** with one click; the viewer link appears when spark has uploaded it.
  - **Not installed yet?** rconsole offers to install spark from Modrinth.

## Upgrade

Update from Server → Updates as usual. No configuration changes are needed. Offsite backups are off until you set them up.
