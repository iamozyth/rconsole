**rconsole 4.4.2** installs the right build of plugins that ship one per server software.

## Fixed

- Plugins that publish a separate build per loader on Modrinth (BlueMap: `5.29-paper` and `5.29-spigot`) were installed and updated as whichever build was uploaded last, which put BlueMap's Spigot build on Paper servers. Installs and updates now pick the build for the server's own software first (Paper/Purpur → Paper, then Spigot, then Bukkit), as long as it belongs to the newest release.
- A plugin already installed as the wrong build shows an update to the matching build of the same release, so one click in Plugins swaps it.
