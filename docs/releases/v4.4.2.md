**rconsole 4.4.2** fixes the world size, the server switcher and two-line dates.

## Fixed

- **World size showed a few MB** for a world restored from an older backup. The archive's folders were private to the server's user (0700), so rconsole, which reads worlds through the server's group, couldn't see the region files. rconsole now has its helper make such folders group-readable (read only, nothing becomes writable) and measures again, and every restore does the same. Until then the size shows with a "+".
- **"Manage servers" and "New server" in the server switcher sometimes did nothing.** The menu was rebuilt when the server list arrived; a click that started before and ended after that was lost. The menu now only changes when the list changes, and its links work even without the click handler.
- **Dates take one line** in every table (worlds, backups, offsite copies, tasks, builds, addresses); "2 hours ago" moved to the tooltip.
