**rconsole 4.0** installs and runs your Minecraft server itself. Pick the software and version; rconsole does the rest, with the security model you know.

## New

- **Servers, installed for you** (Server → Servers, admins):
  - **Software:** Vanilla, Paper, Purpur, Folia, Fabric, Quilt, Forge, NeoForge and the Velocity proxy, with the Minecraft version and build from the publisher.
  - **Java:** the Eclipse Temurin runtime each version needs is installed automatically, side by side. No system Java.
  - **Verified:** every download is checked against its publisher's checksum and comes from the publisher's own servers only.
  - **Ready to play:** the mod loader's installer runs when there is one, RCON gets a random password, and `eula=true` is only written after you accept the Minecraft EULA.
- **Each server in its own sandbox:** `rconsole-mc@<name>.service` runs it as the Minecraft user, writable only in its own folder, without rconsole's secrets, with Aikar's flags and the memory you choose. It stops cleanly, comes back after a crash, and can start after a reboot.
- **Console without RCON:** commands go to the server's stdin, so they work before RCON is up, while it hangs, and on Velocity.
- **Updates and rollback for every distribution:** newer builds and Minecraft versions of the server's own software, installed after a world backup, with the previous version kept.
- **Fresh installs:** the installer no longer needs an existing server (`--new`, or when none is found).
- **Real memory use:** the header shows the Java heap your server really uses (live data after the last garbage collection) out of its maximum, from a GC log rconsole turns on. The host's memory and the recent peak are in the tooltip, and Insights charts it.
- **Switch servers on purpose:** next to a server rconsole attaches to, installed servers stay in the background until you press **Show**; then console, players, worlds and updates switch to it.

## Better

- **Same views, new server:** the server rconsole installed becomes the one it shows: console, players, worlds, backups, plugins and updates work on it as before.
- **Bring your world:** back up your old world and restore it over the new server's from Worlds.
- **EssentialsX:** players and game time show again on servers where Essentials replaces `/list` and `/time`, and maintenance mode kicks the right players there.
- **Deleted servers** are archived in `deleted-servers/` in the backup folder, apart from world backups.
- **Velocity** listens on the port you chose and needs no Minecraft EULA.
- **Paper and Folia updates** for a server rconsole attaches to use the same verified catalog.
- **`sudo node cli.js …`** no longer leaves the account file unreadable for rconsole.

## Upgrade

Update from Server → Updates. The update installs the new `rconsole-mc@` units and the polkit rule, and creates `/srv/minecraft-servers`.

A server you already run keeps working exactly as before.
