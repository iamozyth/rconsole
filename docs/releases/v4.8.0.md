**rconsole 4.8.0** lets you give people a different role on each server, or no access at all.

## New

- **Per-server access.** Every account keeps its global role and can have its own role on single servers: `none` hides a server completely, `viewer`, `moderator` or `admin` replace the global role there. A friend can run their own server as admin without seeing yours. Set it under **Settings → Users & sign-in → Access**, or with `node cli.js user access <name> <server|attached> <role|none|default>`.
- The per-server role covers everything about that server (console, players, world, backups, automation, its row on the Servers page). **Show** needs admin on the target server.
- Settings for rconsole itself (users, sign-in, notifications, offsite backups, updates, audit log, adding servers) always follow the global role.
- Someone without access to the server rconsole shows gets a page listing the servers they can use instead of empty panels.
- `user list` shows per-server roles; the Users table has a Servers column.

## Notes

- Per-server changes take effect on the next request. Changing the global role still signs the person out.
- `REQUIRE_2FA=admin` counts someone who is admin on any server as an admin.
