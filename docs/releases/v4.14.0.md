**rconsole 4.14.0** adds a time machine to every player's profile: see what they carried at each backup and put it back.

## New

- **Players → profile → Time machine** (moderators look, admins restore): pick a backup and see the player's inventory, armor, offhand and ender chest as they were then, with what is missing now and what they picked up since.
- **Restore** puts back the inventory, the ender chest or both from that backup. Position, health, levels and the world stay as they are now.
- **Online players** are kicked with a message after you confirm, the server saves them, and they rejoin with the old inventory.
- **Undo**: the file a restore replaces is kept (the ten newest per player in `BACKUP_DIR/.player-restores/`), and Undo goes back to it.

## Under the hood

- The first look at a backup takes only the player files out of it, into `STATE_DIR/timemachine/`; the copy is dropped with the backup.
- The new helper job `player-restore` changes only the restored tags and writes the file back byte for byte otherwise.
