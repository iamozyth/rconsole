**rconsole 4.21.0** can ask Claude what a problem means. Optional, with your own API key, off by default.

## New

- **Explain this problem**: each entry in Problems gets an **Explain** button (admins) once it is turned on under **Settings → System → Explain problems with Claude** with your own Anthropic API key. Claude says what happened, how serious it is (safe to ignore, minor, important, urgent), the likely cause and what to do.
- Before anything is sent, player names become Player1, Player2, …, chat lines are removed, and IP addresses, UUIDs, e-mail addresses and anything that looks like a password, token or key are masked. The drawer shows the exact text that will be sent.
- Sent: the problem, the log lines around its last occurrence, the server software and version, and plugin or mod names and versions. Straight to `api.anthropic.com`, nothing in between.
- Claude Opus 5.5 by default; Sonnet 5.5 or Haiku 5.5 cost less. At most 20 explanations an hour; the last 50 answers are kept.
- The key can also come from `ANTHROPIC_API_KEY` in `/etc/rconsole.env`. It is stored with mode 600 and never sent back to the browser.
