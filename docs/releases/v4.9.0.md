**rconsole 4.9.0** installs Modrinth modpacks as new servers.

## New

- **Modpack** in Servers → New server: search Modrinth, pick a pack and its version. The loader (Fabric, Quilt, Forge or NeoForge) and the Minecraft version come from the pack.
- The helper downloads the `.mrpack` (SHA-512 from Modrinth) and every mod in it that a server needs (SHA-512 from the pack, only from Modrinth, GitHub or GitLab). Mods the pack marks as client-only are left out. The pack's `overrides/` and `server-overrides/` are copied over the server.
- The pack's `server.properties` settings are kept; rconsole still sets the port, RCON with a random password and, with the recommended settings, the whitelist.
- A pack that tries to write outside the server folder or replace `instance.json`, `eula.txt` or the whitelist is refused, and nothing is left behind.
- The Servers list shows which pack and version a server came from.

## Fixed

- **New server** failed for every game server since 4.4.0: the Minecraft EULA checkbox had gone missing from the form, so pressing Install did nothing. It's back.

## Notes

- Download jobs may now run 40 minutes (was 25) so a big Forge pack fits; self-update installs the changed unit.
- Updating an installed pack to a newer pack version isn't built in yet.
