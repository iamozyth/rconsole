**rconsole 4.4.1** makes BlueMap work in the Map tab.

## Fixed

- **BlueMap showed "Failed to load BlueMap webapp! Make sure you have WebGL2 enabled"** inside World → Map. WebGL was fine: BlueMap reads the browser's local storage while it starts, and the map's sandbox (which keeps it away from rconsole's page, cookies and API) makes that fail. Map pages now get local storage, session storage and cookies in memory instead; BlueMap's own settings reset when the tab closes.
- The map's "Open in new tab" button moved to the bottom left, clear of BlueMap's controls.
