**rconsole 4.0.1** is a security update. Update now: **Settings → About → Update**, or `git pull` and `sudo systemctl restart rconsole`.

## Fixed

- **A malformed cookie could crash rconsole.** One request, without signing in, stopped the process. systemd brought it back, but everyone was signed out and a running update, restart countdown or world operation stopped halfway. Malformed requests now get an error and rconsole keeps running.
- **Nobody can lock you out of your account anymore.** Failed sign-ins used to count per username too, so anyone could block an account for 15 minutes with five wrong passwords. They now count per address, and per address and name.
- **Viewers no longer see player addresses.** Addresses in the console, the log search, problems and the IP ban list are masked for viewers, as the role always promised. Moderators and admins see them as before.
