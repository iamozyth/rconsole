**rconsole 4.22.0** edits game rules.

## New

- **World → Game rules**: every game rule of the running server with a plain description, grouped (players, mobs, world, chat, commands), the most used ones first, and a search. Rules from newer versions, mods and datapacks show up too, since the list comes from the server itself.
- Changes apply right away over RCON, no restart. Paper keeps game rules per world: rules that differ between the Overworld, Nether and End are marked, and a change goes to all worlds unless you pick the Overworld only.
- Works with the Minecraft 26 rule names (`keep_inventory`) and the older ones (`keepInventory`).
