                          Set up the live map

                          rconsole shows BlueMap, squaremap or Dynmap here, behind your rconsole sign-in, so the map doesn't need to be public.

                          1. Install a map plugin. Server → Plugins, search “squaremap” or “BlueMap”, install, then restart the server.
                          2. Keep it private. Let the plugin's web server listen on 127.0.0.1 only; squaremap: internal-webserver.bind: 127.0.0.1.
                          3. Come back here. rconsole finds the plugin and its port and offers to show it.

                                            Backups and updates
                                            
          
                                            
            
            
            
                                            
              
              
                                            
            
                                            
            
                                            
          
                                            
        
                                            
        
                                            
          
                                            Explain problems with Claude
                                            Adds an Explain button to Problems: Claude, Anthropic's AI, says in plain words what went wrong and what to do. Off until you turn it on with your own API key; nothing leaves this machine before that.
                                            
          
                                            
            
                                            
              
            
                                            
            
            
            
                                            What is sent: the problem, the log lines around it, the server's type and version and its plugin names. Player names, IP addresses, UUIDs, chat, e-mail addresses and anything that looks like a password or key are taken out first, and you see the exact text before anything is sent.
                                            
            
                                            
          
                                            
        
                                            
        
                                            
          
                                            Set on the server
                                            Folders the sandbox is built around, and safeguards that root-owned services read. They're changed in /etc/rconsole.env only, so a stolen admin session can't move or switch them off. Restart rconsole after editing (sudo systemctl restart rconsole).
