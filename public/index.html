                          Set up the live map
                          rconsole shows squaremap (or BlueMap) here, behind your rconsole sign-in, so the map doesn't need to be public.
                          
        
                            
          
                          1. Install squaremap. Server → Plugins, search “squaremap”, install, then restart the server. 
                            2. 
          
                          2. Keep it private. In plugins/squaremap/config.yml set internal-webserver.bind: 127.0.0.1 and a free port, e.g. 8100.
                            3. 
          
                          3. Point rconsole at it. Add MAP_URL=http://127.0.0.1:8100 to /etc/rconsole.env and restart rconsole.

                          Single sign-on
                          Let people sign in with authentik, Keycloak, Auth0 or another OpenID Connect provider. Their groups there decide their role here.
                          
            
          
                          
          
                          
            
            
                          
              
                            
                
                          1. In authentik: Applications → Providers → Create → OAuth2/OpenID Provider, client type Confidential, a Signing Key selected, and this redirect URI (Strict):
                            2. 
              
                          
              
                          
                Redirect URI
                
                          
              
                          
              
                          
                rconsole URL
                
                          
                
                          The address people open rconsole at. The provider sends them back here.
                          
              
                          
              
                            
                
                          1. Create an Application with that provider, then the groups below, and paste the provider's details here:
                            2. 
              
                          
              
              
              
              
              
              
                          Groups at the provider for each role (comma-separated)
                
                          
                  
                  
                  
                
                          
                
                          Someone in none of these groups is turned away. A changed group applies at their next sign-in.
                          
              
                          
              
                          
                
                
                          Keep this on as a way in when the provider is down. You can turn it off after you've signed in with single sign-on once.

                          Backups on this machine
                          Made before updates and world changes, on demand under Worlds, and on a timetable under Schedule.
                          
            Schedule backups
          
                          
          
                          
        
                          
        
                          
          
                          
            
                          Offsite copies
                          Keep copies of your backups outside this machine, in any S3-compatible bucket: Backblaze B2, Cloudflare R2, AWS S3, Wasabi or MinIO. The copies themselves are listed under Worlds.
                          
          
                          
        
                          
          
          
          
          
          
          
          
          
                          
            Encryption passphrase (optional)
            
            
                          Backups are encrypted on this machine (AES-256-GCM) before they leave it. Without the passphrase they can't be restored: keep it in your password manager.
